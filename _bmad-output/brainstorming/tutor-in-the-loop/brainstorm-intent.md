# Brainstorm Intent: AI Exercise Generation & Metadata Architecture

## 🎯 Feature Overview
Refactoring and clarifying the **AI Exercise Generation** feature to optimize both Tutor UX and AI token efficiency, adhering strictly to the **Tutor-in-the-Loop** product strategy.

---

## 🔑 Key Decisions & Specifications

### 1. Generation & Metadata Schema
- **Direct AI Output**: When the tutor requests AI to generate homework/exercise questions, the AI prompt will instruct the model to generate:
  - Question content, options, and correct answers.
  - **Topic Tags**: Granular grammatical/vocabulary topic tags (e.g., `Past Simple`, `Travel Vocab`).
  - **CEFR Difficulty Rating**: Explicit difficulty band categorized under the CEFR scale (**A1, A2, B1, B2, C1, C2**).

### 2. Tutor Curation & Edit Flow (Tutor-in-the-Loop)
- AI-generated exercises are saved as **Drafts**.
- Tutors can view, add, edit, or delete questions manually before publishing to students.
- If a tutor edits question text, the CEFR level and tags generated by AI remain editable so the tutor can override them if desired.

### 3. Standards & Scalability
- **CEFR Standardization**: Using international CEFR levels instead of abstract 1-100 numerical scores provides immediate clarity to English tutors and aligns with standard curriculum frameworks.
